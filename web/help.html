01 / 工作区

项目与存储

工作台可以同时展示当前浏览器里的本地项目和账号下的云端项目。项目卡片会标明来源；打开已有项目时，保存仍回到它原来的位置。

本地浏览器

留在当前设备

项目保存在此浏览器的站点数据中。登录或云端服务异常时，本地项目仍可使用。更换浏览器、设备或清除站点数据不会自动迁移这些内容。

云端账号

账号内私有保存

登录后可打开云端库。云端项目需要网络与有效账号权限；管理员身份本身不会获得他人私有项目的读取权。

迁移会复制。“复制到云端并核对”会验证云端副本，本地原项目仍保留。两份项目此后各自保存，不会自动同步。

新建项目的保存位置由账号面板中的“新建项目保存位置”决定。切换位置只改变后续新建项目的目标，不会移动现有项目。

02 / 外观

主题库

主题库分为内置主题、个人本地主题和账号私有的云端主题。内置主题只读；个人主题可在所属库中管理。云端主题不会公开给其他账号。

  • 导入与导出主题可通过 JSON 文件在本地保存或迁移。导出的文件由你管理，不代表平台备份。
  • 版本已发布版本不可覆盖；更新会形成新的版本。上传云端会创建独立云端副本，原本地主题保留。
  • 预览预览用于查看示例效果。实际字体、图表及渲染结果可能因环境而不同。

03 / 找回内容

历史、冲突与恢复

云端项目会记录服务端修订历史。可以查看修订、比较快照，并将较早版本恢复为一个新的当前修订。恢复不会删除之后的历史记录，也不是数据库回滚；需要项目读取与写入权限。

1

先保留当前页面与提示，不要反复提交旧内容。

2

重新读取云端项目，确认最新修订，再决定是继续编辑还是从历史版本恢复。

3

若页面提供“恢复草稿”，可恢复为独立项目或另存为本地副本；原云端项目不会被草稿恢复覆盖。

离线边界。本地项目可以在当前浏览器使用。云端编辑不会在断网时自动同步；保存失败时可能留下浏览器本地恢复草稿。草稿依赖原浏览器站点数据与对应账号，清除站点数据或存储空间不足可能使其不可用。

云端历史仅适用于云端项目。恢复草稿不是服务端备份，也不保证跨浏览器或设备可用。需要编辑器内具体恢复操作时，请参阅现有恢复说明 ↗。

04 / 自动化

Agent 接入

在工作台打开“Agent 接入”可创建个人访问令牌（PAT）并设置权限。默认有效期为 30 天，最长 365 天。令牌只在创建时显示一次；请安全保存，避免放进截图、文档、网址或源代码。遗失后撤销旧令牌并创建新的。

⌘
从最小权限开始

只勾选 Agent 当前需要的操作，并尽量限定项目范围。令牌可设置到期时间；不用时可随时撤销。

API 示例

将服务器地址与令牌放入当前终端的环境变量，然后用只读权限列出可访问的项目：

export SP_API_URL="https://你的服务地址"
export SP_API_TOKEN="在此终端安全设置令牌"
curl --fail-with-body \
  --header "Authorization: Bearer $SP_API_TOKEN" \
  "$SP_API_URL/api/v1/projects"

此示例需要 projects:read。请勿把真实令牌粘贴到共享终端或公开日志中。

远程 MCP 与 OAuth

支持该功能版本的服务可提供远程 HTTP MCP 入口 /mcp。MCP 传输使用无状态 JSON，不提供 MCP 特有的 SSE 通知流。OAuth 授权码与 PKCE 流程需要用户同意，并可限制项目范围；是否可用取决于部署中的服务版本。第三方桌面客户端与真实浏览器登录尚未逐一验收，请先确认客户端兼容性。OAuth 令牌面向 MCP 入口，不等同于网站登录，也不替代本地 stdio Bridge 所用的 PAT。

开发分支已实现云端项目修订变更的 SSE 提示接口，供浏览器获知项目状态变化；主控真实浏览器验收尚待完成，生产部署尚未进行。它与 MCP 工具传输分开，也不会自动读取、合并或保存正文。

云端原生 MCP 当前共有 20 个工具，其中新增 4 个历史工具：sp_list_revisions 列出修订、sp_get_revision 读取快照、sp_revision_diff 比较修订、sp_restore_revision 将较早内容提交为新修订。前三项需要 projects:read；恢复需要 projects:write、当前修订号和稳定的 mutation ID，并遵守项目编辑租约。

本地代码与测试通过不代表功能已部署到你的服务。若服务未提供对应入口或授权选项，请按当前部署实际显示为准。远程 MCP /mcp 仍使用无状态 JSON 传输，没有 MCP SSE 通知流。

05 / 访问范围

权限与限制

Agent 授权按操作和数据范围分别控制。项目权限与主题权限相互独立；不要因为一次集成需要读取项目，就一并授予删除或主题发布权限。

projects:read列出并读取获准访问的项目
projects:create创建项目
projects:write编辑项目与恢复历史修订
projects:export导出获准访问的项目
projects:delete删除项目；按需单独授予
assets:write服务端支持的资源写入授权；当前 PAT 表单未列出
themes:read / write / publish读取、管理或发布个人主题

项目白名单会进一步限制可访问的项目。私有项目仍由所属账号控制；管理员没有绕过私有内容权限的特权。云端主题能力也取决于服务部署和令牌范围。

06 / 快速解答

常见问题

为什么本地项目没有出现在另一台设备？

本地项目存放在创建它的浏览器中。登录云端账号不会自动上传它；需要主动复制到云端，且本地原件会保留。

我忘了保存 PAT，还能再次查看吗？

不能。撤销旧令牌，再创建一个新令牌，并只授予必需权限。

断网后能继续编辑云端项目吗？

云端改动不会自动离线同步。若已有本地恢复草稿，可按页面提供的选项另存为本地副本；恢复草稿依赖原浏览器站点数据。

本地项目也有云端历史记录吗？

没有。服务端修订历史适用于云端项目。

没有找到匹配内容。试试“本地”“恢复”或“权限”。
