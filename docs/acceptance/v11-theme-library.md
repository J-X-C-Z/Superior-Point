# v1.1 主题库与工作台验收记录

日期：2026-10-11。规划版本 v1.1；应用版本仍为 0.1.0-alpha。开发分支 `roadmap/v1.1-foundation`，基线 `73bc6f7`。该记录不是 Stable 发布或生产部署证明。

## 已实现

SP-041～055 的主闭环已进入源码：复合项目来源、统一列表/来源筛选/上传映射/恢复中心、原位重命名、独立 Agent 接入中心；版本化主题 schema、六套原创 MIT 内置主题、四类真实样例（16:9/4:3）、本地个人主题编辑/版本/导入导出/收藏/归档、私人云端 ThemeService、回读上传、主题应用预览/Core 原子批次/一次撤销，以及五个受权 MCP 主题工具。SP-073 增加云端历史列表、内容差异与恢复新修订，保留旧历史。

主题应用只改变实际支持的样式字段。默认保留手工覆盖；无基线的旧对象显式样式视为手工设置。重置模式明确确认，仍不重排位置或改写内容、图片、备注与动画。文稿嵌入固定主题版本和哈希快照，主题升级或归档不会自动改文稿。

- 实际 SDK → stdio Bridge → HTTPS/PAT 业务 API → PostgreSQL 的主题读/预览/保存/应用通过；覆盖同账号浏览器活动租约、幂等回放、跨账号、项目范围、Scope、吊销与旧修订拒绝。
- 云端历史恢复在独立 PostgreSQL 中通过：恢复为新修订、保留旧历史/主题/资产/备注/未知字段，活动租约、CAS、跨用户、吊销和软删除边界检查通过。

## 修复与限制

审查确认并修复：合法极端主题间距会造成负数预览几何；单张预览失败不再中断整个画廊。浏览器请求以 `X-SP-Account-ID` 固定账号，服务端拒绝其他标签页改变会话后的旧工作区读取/写入；草稿仍按原账号保留。

SP-056/057 尚不能标全量完成：Firefox 计算机使用工具拒绝控制，未验证 Firefox 主题完整闭环；PowerPoint 视觉保真未验收；主题列表/资产最大容量压力未完成。通用 SVG 字体/行距、图表轴与原生编辑器有降级/差异，详情页明确提示；主题不会自动重新排版或分发字体。

未部署此批次、未执行生产迁移；未安排整机重启。备份按用户“先不备份”继续延期。后续须按 PR/CI 和生产变更验收分层推进，不将规划中的远程 MCP/OAuth、录制、PPTX 高级能力或 Stable 视作已实现。
