# 服务版用户指南（Alpha 候选）

此服务仍是待验收候选，尚未生产发布。管理员应提供可信 HTTPS 服务地址和账号。当前项目数据通过服务端 API 保存；不要把本地演示工作台中的 IndexedDB 项目视为已同步到服务端。

## 登录与账号安全

登录后浏览器会话由 HttpOnly Cookie 维护。写操作需要同源请求保护；若会话或 CSRF 校验失败，请重新登录并刷新页面。首次登录后应设置个人强密码。密码至少 12 个字符。管理员可以禁用账号、变更角色、撤销会话或重置密码；令牌和管理员操作会进入审计记录。

## 项目与保存

服务 API 支持创建、读取、编辑、重命名、回收站、恢复、导入、快照、幻灯片读取与静态 SVG 预览、验证和 HTML 导出。并发编辑使用修订号检查与短期写租约；出现版本冲突时先重新读取最新项目，再决定如何重试，不要覆盖冲突后产生的内容。`audience-html` 是面向展示的导出，不保留完整编辑数据；应保留 `editable-html` 或 JSON 备份作为可编辑副本。

## 访问令牌与 MCP Bridge

个人访问令牌只在创建时显示一次，应按需要选择最小 scopes 和项目范围，设置有效期并安全保存。遗失后撤销并创建新令牌。管理员可审查及撤销令牌。MCP Bridge 是单独的 stdio 客户端，需要服务地址和令牌配置；文件导入/导出可由 `SP_BRIDGE_ROOT` 限定在专用目录。它不表示本地单文件演示工作台已与服务端实时同步。

OAuth/OIDC 登录、生产 DNS 与容器部署，以及离机备份恢复尚未完成验收。不要将 Alpha 候选用于未备份的重要生产资料。
