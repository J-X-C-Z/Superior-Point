# Superior Point 帮助中心

本页说明当前 v1.1 服务代码中的项目存储、主题、历史、Agent 接入和恢复边界。实际可用功能取决于部署的服务版本、账号和令牌授权。

## 项目与存储

工作台可同时展示本地项目和云端项目，并标明每个项目的来源。打开已有项目后，保存仍回到其原始位置。新建项目则保存到账号面板当前选择的位置；更改此选择不会移动已有项目。

- **本地项目**保存在当前浏览器的 IndexedDB 站点数据中。本地项目可在云端故障时继续使用，但不会自动出现在另一台设备。更换浏览器或清除站点数据可能导致无法访问。
- **云端项目**保存在登录账号下，需要网络连接和有效权限。管理员也没有读取他人私有项目的默认特权。
- **迁移**是将本地项目复制到云端并核对结果。本地原项目保留；两份项目后续各自保存，不会自动同步。

## 主题库

主题分为内置只读主题、个人本地主题和账号私有的云端主题。导入、导出通过 JSON 文件完成；导出的文件由用户自行保存，不代表平台备份。发布后的主题版本不可覆盖，更新会产生新版本。把本地主题上传云端会创建独立副本，不会移除本地原件。主题预览是静态示例，实际字体、图表和渲染效果可能受环境影响。

主题编辑细节与格式说明见[主题文档](../THEMES.md)。云端主题功能取决于服务部署和令牌的 `themes:read`、`themes:write`、`themes:publish` 权限。

## 云端历史、冲突与恢复

云端项目有服务端修订历史，可列出、比较快照，并将较早修订的内容作为**新的当前修订**提交。历史记录不会被改写；这不是数据库回滚。读取历史需要 `projects:read`，恢复需要 `projects:write` 和有效的项目编辑租约。历史功能不适用于本地项目。

遇到修订冲突时，先重新读取云端项目并确认当前版本，再继续编辑或恢复历史。不要盲目重复提交旧版本。

云端编辑保存失败时，浏览器可能留下本地恢复草稿。草稿保存在当前浏览器站点数据中，并绑定原账号；清除站点数据或浏览器存储空间不足可能使它不可用。恢复草稿可以创建独立云端项目，或另存为本地副本；不会覆盖原云端项目。断网时云端更改不会自动同步，本地项目仍可继续使用。具体编辑器恢复步骤见[现有恢复说明](../RECOVERY.md)。

用户导出的 JSON 或 HTML 文件只是用户保存的副本。该帮助页不承诺服务端备份或生产恢复能力。

## Agent PAT 与 API

从工作台打开“Agent 接入”，可创建个人访问令牌（PAT）、选择操作权限、设置项目范围和到期时间，也可撤销令牌。默认有效期为 30 天，最长 365 天。令牌只显示一次；遗失后撤销旧令牌并创建新令牌。将其保存在安全位置，避免放入源代码、截图、网址或共享日志。

以下示例使用只读 `projects:read` 范围。请在自己控制的终端安全设置环境变量：

```sh
export SP_API_URL="https://你的服务地址"
export SP_API_TOKEN="在此终端安全设置令牌"
curl --fail-with-body \
  --header "Authorization: Bearer $SP_API_TOKEN" \
  "$SP_API_URL/api/v1/projects"
```

令牌权限分为 `projects:read`、`projects:create`、`projects:write`、`projects:export`、可选的 `projects:delete`、服务端支持的 `assets:write`（当前 PAT 创建表单未列出），以及 `themes:read`、`themes:write`、`themes:publish`。按实际需求只授予必要权限；项目白名单可进一步限制访问范围。主题权限与项目权限分开。管理员没有绕过私有内容权限的特权。

支持相应功能版本的服务提供远程 HTTP MCP 地址 `/mcp`。MCP 传输接受无状态 JSON 请求，没有 MCP SSE 通知流。另有独立的云端项目修订 SSE 提示接口，已在开发分支实现，供浏览器获知项目修订状态变化；主控真实浏览器验收尚待完成，生产部署尚未进行。它只提示状态，不会自动读取、合并或保存正文。OAuth 授权码 + PKCE 流程要求用户同意，并允许设置项目范围；OAuth 仅用于 MCP 入口，不能代替本地 stdio Bridge 所需的 PAT。OAuth 能否使用取决于服务端部署版本。第三方桌面客户端与真实浏览器登录尚未逐一验收，不保证兼容性。以实际服务提供的入口和授权选项为准。

云端原生 MCP 当前共有 20 个工具，其中新增 4 个历史工具：`sp_list_revisions` 列出修订、`sp_get_revision` 读取快照、`sp_revision_diff` 比较修订、`sp_restore_revision` 将较早内容提交为新修订。前三项需要 `projects:read`；恢复需要 `projects:write`、当前修订号和稳定的 mutation ID，并遵守项目编辑租约。恢复不会覆盖或删除已有历史。

## 存储配额、登录会话与固定分享

服务可配置全站每账号的活跃项目数和留存内容配额，并在达到阈值时显示告警。用量包括项目数据、历史修订、主题版本、变更回执和固定分享页面；移入回收站不会释放留存数据，过期或已撤销分享的固定页面也继续计入用量。该配额衡量数据库保留内容，不是数据库物理磁盘或云主机磁盘上限。达到上限时，新增项目、扩容、发布新版本或部分恢复操作可能失败；现有资料不会因此被自动删除，读取和导出仍按各自权限开放。请查看“存储用量”及页面给出的恢复指引，不要为了腾出配额盲目重复写入。

工作台“Agent 接入”中的“活跃登录会话”只列出当前账号的有效浏览器会话。可以退出单个会话；退出当前会话会使当前浏览器重新登录。部分退出操作要求再次验证当前密码。修改密码会退出该账号的所有浏览器会话，但不会自动撤销 PAT；需要分别检查并撤销不再使用的 Agent 授权。退出会话不会删除项目。

固定分享链接由当前项目所有者在已登录的工作台创建和撤销；PAT、OAuth 或管理员身份本身不能代替项目所有权管理链接。链接展示创建时已保存的固定修订，只供只读放映，不会随之后编辑更新。工作台当前创建 7 天有效链接；服务端允许的最长时间为 30 天。分享链接持有者可以转发，也可能保存收到的页面内容。

**到期、暂时不可访问和永久撤销不是一回事。** 到期后该链接不能再打开，需要重新创建链接。项目被移入回收站或账号暂时停用时，链接会被阻断；在仍未到期且未撤销的情况下，恢复有效账号和项目可能重新允许访问。若要永久停用链接，应在工作台分享管理中点“撤销”；撤销不可恢复，也无法收回访客此前下载或另存的内容。链接只在创建时显示一次，列表不能找回原链接。

## 常见问题

**本地项目为何没有出现在其他设备？** 本地项目存放在当前浏览器。需要手动复制到云端才能在账号下使用；复制不会删除本地原件。

**能否再次查看已创建的 PAT？** 不能。撤销遗失的 PAT，再创建新令牌。

**断网时能否继续编辑云端项目？** 云端更改不会自动同步。若页面显示可用恢复草稿，可将它保存为本地副本；草稿依赖原浏览器站点数据。

**本地项目是否有云端历史？** 没有。服务端修订历史只适用于云端项目。

**退出登录会删除项目或撤销 Agent PAT 吗？** 不会。退出浏览器会话只撤销该会话；项目和 PAT 需要分别按其所有者及授权管理。

**分享链接到期后能恢复吗？** 不能延长已创建链接的有效期；到期后需创建新链接。被撤销的链接永久失效。未到期且未撤销的链接若因回收站或账号停用暂不可用，在项目和账号恢复有效后可能重新打开。
