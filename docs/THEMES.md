# 主题库使用指南

本指南说明当前仓库中的主题库。它不代表未发布的线上版本；是否可在某个部署中使用，以该部署是否包含「主题库」入口为准。

## 浏览与预览

从工作台打开「主题库」，按来源查看内置、本地和当前账号的云端主题，也可按名称、标签、颜色和画布比例筛选。打开「详情与四页预览」可切换 16:9 或 4:3，并查看封面、正文、数据和图文样例。预览是静态 SVG；系统字体可能回退，字体行距和图表外观可能与编辑器不同。

内置主题只读。选择「另存为我的主题」或「创建我的主题」后，可在「编辑 / 重命名」中修改可编辑的颜色、文字规则和布局参数。保存修改会发布一个新的个人主题版本；旧版本仍固定保留，已有文稿也继续引用其原版本。

## 导入、导出与云端

「导入主题 JSON」会校验主题结构、资源格式与哈希，再保存为新的本地主题。主题包上限为 12 MiB，内嵌图片只支持 PNG、JPEG 和 WebP；SVG、HTML、脚本、外部资源和字体文件不支持。字体只使用设备已安装的字体及其后备字体，不会被自动打包或上传。

在主题详情中选择「导出 JSON」可导出当前固定版本。登录后，本地主题还可选择「上传到我的云端」。上传会在账号名下新建云端主题并回读核验，保留本地原件；本地与云端是两个来源身份，不会按标题覆盖。云端主题只对所属账号可见。

## 应用到文稿

在主题详情中选择「应用到已有项目」，选择目标文稿后查看样例预览。默认方式是「保留手工覆盖」：更新受支持的主题样式，同时保留内容、图片、备注、动画和元素坐标。应用作为一次文稿修改，可用编辑器「撤销」撤回。

「重置为主题样式」会覆盖受支持的手工颜色、字体和组件样式，但仍保留文稿内容与位置；选择后还需再次确认。主题应用不会承诺自动重排或改变所有渲染器效果。发生修订冲突或失去写入权时，请先重新打开最新文稿再试，不要用旧版本覆盖。

## Agent 与 PAT

云端 stdio MCP Bridge 的主题能力使用个人访问令牌（PAT）。只授予完成工作需要的范围：

- `themes:read`：列出、读取和预览主题。
- `themes:write`：导入个人主题、管理收藏以及归档主题。
- `themes:publish`：向已有主题发布一个新的固定版本。
- 对文稿应用主题还需要 `projects:write`；如令牌设有项目白名单，目标项目也必须在白名单中。

主题工具包括 `sp_list_themes`、`sp_get_theme`、`sp_preview_theme`、`sp_save_theme` 和 `sp_apply_theme`。应用默认保留手工样式；只有调用方明确选择重置才会覆盖受支持的手工样式。远程 HTTP MCP 与 OAuth/OIDC 尚未实现。

## 已知兼容边界

主题预览提供四页静态样例，主要用于检查样式和比例，不是最终放映截图。当前没有字体分发；字体或行距可能降级。图表的静态 SVG 与编辑器原生图表可能采用不同坐标轴表现。PNG、JPEG、WebP 是主题包支持的图片格式。PowerPoint 和 Firefox 的主题视觉一致性没有据此验收。

完整接口与权限边界见 [主题 API 说明](api/themes.md) 和 [OpenAPI](api/openapi.yaml)；已记录的兼容性检查见 [主题兼容性验收](acceptance/theme-compatibility.md)。
