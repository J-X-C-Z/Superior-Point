# 主题库使用指南

本指南说明 Superior Point 主题库的使用方式。主题包含视觉规则，也可以包含声明式运动规则；模板仍负责页面与叙事结构。切换主题不会自动重排页面。

## 浏览主题和查看样例

从工作台打开「主题库」，可以浏览内置、本地和当前账号的云端主题，按名称、标签、颜色和画布比例筛选。列表以每页 24 条显示元数据；主题详情展示设计原则、适用场景、避免事项、独立特征、视觉规则、运动语言、来源、版本和许可信息。

详情中的样例包含封面、正文、数据、图文和章节页，可用「使用主题新建」创建可编辑的演示文稿。屏幕中的主题预览仍是静态 SVG；字体、行距和图表可能与编辑器不同。它不是放映效果或 PowerPoint 保真证明。

## 预览并应用到文稿

选择「应用到已有项目」后，先选目标文稿和应用方式，再选「整篇」「单页」或「选中页」。单页和选中页需要勾选页面。点击「预览变更」会生成只读计划，显示将变更的样式、保留的手工覆盖、文稿修订号和兼容性诊断；预览不会写入文稿。更改页面、目标或应用方式后，需要重新预览。

默认「保留手工覆盖」只更新主题驱动且仍匹配旧主题基线的支持样式。确认后，主题引用会固定到所用版本；文本、图片、备注、对象 ID、位置、页面结构和已有动画意图保持原样。保存后的主题应用可通过编辑器撤销。选择「重置为主题样式」并再次确认后，会覆盖所选页面中支持的手工样式，仍不改变内容和位置。

运动语言会记录进入、退出、转场、时长、缓动和减少动态设置。兼容性诊断只读取并报告现有动画意图；主题切换不会生成、替换或删除动画。可编辑与观众 HTML 导出会响应浏览器的“减少动态效果”偏好，关闭转场和动画效果，同时保留键盘与片段导航。编辑器、网页放映、HTML 和 PPTX 的支持程度不同；诊断结果用于说明已知限制，不代表放映效果或 PowerPoint 保真保证。

## 主题版本、个人副本与云端

内置主题只读。个人主题可以另存、修改、导入或导出 JSON；发布更新会形成新版本，已有文稿保留自己的固定主题快照。历史版本列表可查看版本元数据并读取某个不可变版本。复制主题会创建独立条目，不会改写其来源版本。登录后可把本地主题上传为账号私有副本；上传后仍保留本地原件。

新设计语言字段会按封闭的声明式结构校验身份、视觉和运动规则，包括字段类型、范围、允许值和时长顺序；未知字段、任意 CSS/脚本或外部加载地址不会作为受信运行时代码执行。兼容旧主题时，旧格式不强制要求 `designLanguage`。主题包最多 12 MiB，内嵌图片最多 2 MiB、总计最多 8 MiB，支持 PNG、JPEG 和 WebP，并校验内容哈希。受限二进制资源接口按固定主题 ID、版本和哈希校验资源后才返回图片字节；字体只引用设备上已安装的字体，不会随主题打包。

可以使用 `node tools/theme-validate.js <JSON文件> [--kind manifest|document] [--fonts 字体名,字体名]` 检查主题清单或文稿，并输出 JSON 诊断。服务端另提供项目主题兼容诊断 API；报告覆盖资源缺失/哈希、引用版本、字体回退、运动与通用 HTML 限制。它是元数据静态诊断，不会加载字体或外部资源，也不能证明真实渲染或 PowerPoint 保真。

## 功能边界

主题编辑器提供规则编辑。主题预览使用通用渲染器，字体、富文本、复杂动画、母版和图表在编辑器、网页放映、HTML 与 PPTX 中可能表现不同；PowerPoint 导出不保证与编辑器完全一致。PPTX 会包含演讲备注和隐藏幻灯片，因此不适合用作观众脱敏分享；请使用观众 HTML 导出。PPTX 字体只引用、不嵌入，图表字体为 Arial；图像裁切、滤镜和适配会烘焙为位图，原始裁切参数不保留，但仍可在 PowerPoint 中重新裁切输出位图；组合会展平，图表与表格的可编辑性可能不同，动画和转场不导出。主题快照用于固定文稿所用的主题版本，不是项目备份。

接口与权限细节见[主题 API 说明](api/themes.md)、[OpenAPI](api/openapi.yaml)和[主题兼容性验收记录](acceptance/theme-compatibility.md)。
