# 主题库使用指南

本指南说明 `roadmap/v1.2-theme-library` 当前代码中的主题库。主题包含视觉规则，也可以包含声明式运动规则；模板仍负责页面与叙事结构。切换主题不会自动重排页面。

本分支尚未部署。生产环境仍以已核实的部署版本为准；最近记录的基线是 `93ebf03`，新版本上线情况需另行核实。此说明不代表生产已具备本页列出的功能。

## 浏览主题和查看样例

从工作台打开「主题库」，可以浏览内置、本地和当前账号的云端主题，按名称、标签、颜色和画布比例筛选。主题详情展示设计原则、适用场景、避免事项、独立特征、视觉规则、运动语言、来源、版本和许可信息。

详情中的样例包含封面、正文、数据、图文和章节页，可用「使用主题新建」创建可编辑的演示文稿。屏幕中的主题预览仍是静态 SVG；字体、行距和图表可能与编辑器不同。它不是放映效果或 PowerPoint 保真证明。

## 预览并应用到文稿

选择「应用到已有项目」后，先选目标文稿和应用方式，再选「整篇」「单页」或「选中页」。单页和选中页需要勾选页面。点击「预览变更」会生成只读计划，显示将变更的样式、保留的手工覆盖、文稿修订号和兼容性诊断；预览不会写入文稿。更改页面、目标或应用方式后，需要重新预览。

默认「保留手工覆盖」只更新主题驱动且仍匹配旧主题基线的支持样式。确认后，主题引用会固定到所用版本；文本、图片、备注、对象 ID、位置、页面结构和已有动画意图保持原样。保存后的主题应用可通过编辑器撤销。选择「重置为主题样式」并再次确认后，会覆盖所选页面中支持的手工样式，仍不改变内容和位置。

运动语言会记录进入、退出、转场、时长、缓动和减少动态设置。当前的兼容性诊断只读取并报告现有动画意图；主题切换不会生成、替换或删除动画。减少动态偏好目前只记录在诊断中，尚未强制到浏览器播放行为。编辑器、网页放映、HTML 和 PPTX 的支持程度不同，诊断结果不等于真实播放或导出验收。

## 主题版本、个人副本与云端

内置主题只读。个人主题可以另存、修改、导入或导出 JSON；发布更新会形成新版本，已有文稿保留自己的固定主题快照。复制主题会创建独立条目，不会改写其来源版本。登录后可把本地主题上传为账号私有副本；上传后仍保留本地原件。

新设计语言字段会按封闭的声明式结构校验身份、视觉和运动规则，包括字段类型、范围、允许值和时长顺序；未知字段、任意 CSS/脚本或外部加载地址不会作为受信运行时代码执行。兼容旧主题时，旧格式不强制要求 `designLanguage`。主题包最多 12 MiB，内嵌图片最多 2 MiB、总计最多 8 MiB，支持 PNG、JPEG 和 WebP，并校验内容哈希。字体只引用设备上已安装的字体，不会随主题打包。

## 上游来源与许可

Design Systems 上游仓库在 2026-10-12 核对的 revision 是 `f958fd2dce57b9f7650785630bb6713d8a612604`，仓库许可字段当前未确认。主题适配器只接受经人工审阅的原创规则，记录来源与限制；上游资产不会被复制或分发，仓库公开也不代表获得再分发许可。主题详情中的来源信息不构成许可意见。

## 尚未交付或尚未验收

主题编辑器目前提供有限的规则编辑；没有 AI 聊天式主题编辑或自动风格重构。社区分享、审核、评分和发现推荐属于后续 P2。多浏览器真实操作、减少动态播放行为、编辑器/放映器/HTML/PPTX 一致性以及生产发布都要分别验收。生产备份与部署回滚仍按原计划延期，不能把主题快照当作项目备份。

接口与权限细节见[主题 API 说明](api/themes.md)、[OpenAPI](api/openapi.yaml)和[主题兼容性验收记录](acceptance/theme-compatibility.md)。
