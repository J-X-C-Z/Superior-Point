# 服务边界与基础范围

本文件冻结 SP-001～SP-007 的首阶段边界，依据 `service-roadmap-v1.0.md` 与 `foundation-contract.md`。它定义服务入口、信任边界和验收范围，不代表这些能力已实现或已部署。

## 系统边界

Fastify 服务是版本化 REST API 的边界。HTTP 路由把经过会话认证的请求映射为 `Actor`，再调用 AuthService 或 ProjectService。服务只信任认证结果中的 `id`、`role`、`source` 和 `sessionId`；请求体中的身份、角色或所有者字段都不是授权依据。

ProjectService 是项目读写的唯一业务入口。项目文档、修订、锁、幂等收据和审计记录由同一数据库事务维护。Document Core 负责验证并执行其定义的操作；API 不另造元素 patch 格式。数据库错误和文档正文不得进入公开错误响应或审计日志。

## 本阶段范围

| 任务 | 冻结范围 | 验收边界 |
|---|---|---|
| SP-001 | 本服务边界、角色矩阵、`/api/v1` REST/OpenAPI、错误格式与错误码 | 路径、字段、权限和错误语义一致；实现按本契约验证 |
| SP-002 | PostgreSQL 初始 schema、事务迁移、隔离测试库初始化与回滚验证 | 只针对明确的隔离测试数据库；生产数据操作不属于此验收 |
| SP-003 | ProjectService 创建、列表、读取、重命名、回收与恢复 | 每次访问都校验项目 owner；管理角色不绕过 owner 检查 |
| SP-004 | Document Core 操作提交、期望修订 CAS、幂等收据、修订和审计事务、单写者租约 | 冲突或租约失败不提交；成功变更的 revision 恰增一 |
| SP-005 | 用户和会话模型、密码验证、登录、退出、当前身份、CSRF 校验 | Cookie 会话可撤销；禁用账户不能继续认证 |
| SP-006 | Admin/User 服务端授权、账户状态和角色变更、会话撤销、最后管理员保护 | 每个管理操作检查 Web Admin；关键账户变更事务化并审计 |
| SP-007 | 本地首次管理员 bootstrap 与 Admin 创建用户 | 不提供未认证的公网 bootstrap 或公开注册入口 |

## 角色矩阵

`Admin` 与 `User` 是平台角色；项目访问始终另行检查 `owner_id = Actor.id`。管理角色不赋予读取他人私人文档正文的权限。

| API 能力 | 未登录 | Web User | Web Admin | 非 Web Actor |
|---|---:|---:|---:|---:|
| 登录 | 可调用 | 可调用 | 可调用 | 不适用 |
| 当前身份、退出 | 拒绝 | 仅自己的会话 | 仅自己的会话 | 拒绝 |
| 用户列表、创建、状态、角色、会话撤销 | 拒绝 | 拒绝 | 允许（受最后管理员规则约束） | 拒绝 |
| 项目创建、列表、读取、编辑、删除、恢复 | 拒绝 | 仅自己的项目 | 仅自己的项目 | 拒绝 |
| 项目文档与租约 | 拒绝 | 仅自己的项目 | 仅自己的项目 | 拒绝 |

认证失败统一为 `401`。身份有效但角色或所有权不允许时返回 `403`；对项目资源，其他所有者的 ID 与不存在的 ID 一律表现为 `404`，避免泄露项目是否存在。

## 请求与写入边界

- 浏览器会话使用 HttpOnly Cookie。生产 Cookie 必须为 Secure；HTTP 仅在显式开发模式可用。
- 所有写请求校验精确 Origin。Cookie 认证写请求还必须提供 `X-CSRF-Token`；登录本身也校验 Origin。
- 项目 mutation 使用 `expectedRevision` 与 `clientMutationId`。同一主体、项目、mutation ID 和相同请求重放返回原结果；相同 ID 配不同内容返回 `409 MUTATION_ID_REUSED`。
- 文档操作数量为 1～1000。项目快照替换需要有效租约；其他写入同样不得绕过活动租约。
- 租约时长 60 秒。客户端 `holder` 仅用于标识会话，不构成授权；不得主动抢占活动租约。
- 项目删除是可恢复的软删除。列表可用 `trash=true` 请求回收项目；恢复与删除都经过修订 CAS 和审计事务。
- 公开错误采用 `{ "error": { "code", "message", "details?" } }`。`details` 不得暴露口令、Cookie、令牌、SQL 或文档正文。

## 明确排除

本边界只冻结本地服务基础契约和首批 REST 服务能力。UI、客户端数据迁移、Agent 凭据、MCP 接入、远程访问和主机部署不由 SP-001～007 的文档或状态记录宣称完成；分别按路线图的后续任务验收。
