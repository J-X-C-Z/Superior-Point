# Agent skills

Local tickets: see docs/agents/issue-tracker.md. Domain documentation: see docs/agents/domain.md.

Use Ponytail: smallest complete change, reuse existing interfaces, preserve user documents and full backups. Do not edit original vendor editor HTML or generated integration files by hand. Rebuild from the integration builder.

Parallel tasks may own separate files; coordinate changes to shared files. Record actual tests separately from browser acceptance. Never claim a browser process restart from a tab reload.
